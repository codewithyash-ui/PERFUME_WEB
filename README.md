## 📖 Overview

**Noir Essence** is a premium, fully responsive luxury perfume e-commerce website built with pure **HTML5, CSS3, and Vanilla JavaScript**. No frameworks! The website features a stunning black & gold glassmorphism design with modern animations and complete e-commerce functionality.

## ✨ Features

### 🎨 Design Features
- **Premium Luxury Theme** - Black + Gold + Charcoal color scheme
- **Glassmorphism Effects** - Modern frosted glass UI elements
- **Elegant Typography** - Cormorant Garamond + Inter fonts
- **Smooth Animations** - Scroll reveals and hover effects
- **Fully Responsive** - Mobile-first design (works on all devices)

### 🛍️ E-Commerce Features
- Product listings with images, prices, and ratings
- Search products functionality
- Category filtering (Oud, Floral, Amber, Woody)
- Price range filter
- Sort products (price low-high, high-low, name)
- Add to cart with quantity management
- Wishlist functionality
- Coupon code system (LUXE15 for 15% off)

### 📱 User Features
- User registration and login
- Shopping cart with localStorage persistence
- Checkout with dummy payment
- Order ID generation
- Newsletter subscription
- Product quick view
- Toast notifications for actions

### 👑 Admin Features
- Secure admin login (`yash@123` / `admin@123`)
- Admin dashboard with analytics
- Sales chart (Chart.js)
- Total orders, customers, revenue stats
- Product management interface
- Orders management table

### 🚀 Technical Features
- Loading screen animation
- Back to top button
- Sticky navigation bar
- Mobile hamburger menu
- Scroll animations
- Local storage for cart & wishlist
